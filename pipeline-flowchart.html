FoodSeq Reference Database Pipeline

trnL (plant) and 12SV5 (vertebrate) reference databases for dietary metabarcoding · one pipeline, run once per marker · Updated October 2026 (release 2026.10)

Steps ①–⑩ below are one pipeline, run once for trnL and once for 12SV5. Only these differ:

A third variant, trnL c/d (Part A-CD), shares Part A's species list and NCBI pull but extracts the full intron by alignment rather than by primer matching; it is the dashed blue branch below. After a release, the dashed purple branch is how gaps are closed without a cluster rebuild.
